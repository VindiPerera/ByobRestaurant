COLORS & STYLING
═════════════════════════════════════════════════════════════════════════════════

Primary Colors:
  • Button Red:        #dc2626 (Red-600)
  • Dark Red:          #991b1b (Red-900)
  • Light Red:         #fef2f2 (Red-50)
  • Border Red:        #fecaca (Red-200)

Text Colors:
  • Primary Text:      #111827 (Gray-900)
  • Secondary Text:    #4b5563 (Gray-600)
  • Placeholder:       #d1d5db (Gray-300)

Backgrounds:
  • Page Background:   Linear gradient (#f3f4f6 → #e5e7eb)
  • Form Background:   White
  • Demo Box:          Light red gradient

Shadows & Effects:
  • Container Shadow:  0 20px 60px rgba(0,0,0,0.15)
  • Button Hover:      0 12px 32px rgba(220,38,38,0.4)
  • Focus Glow:        0 0 0 3px rgba(220,38,38,0.1)

Borders & Radius:
  • Container Radius:  16px
  • Input Radius:      8px
  • Border Width:      2px (input), 1px (demo box)


INPUT FIELD STATES
═════════════════════════════════════════════════════════════════════════════════

DEFAULT STATE:
  • Border: 2px solid #e5e7eb
  • Background: White/Transparent
  • Text Color: #111827
  • Icon Color: #9ca3af

FOCUS STATE:
  • Border: 2px solid #dc2626
  • Shadow: 0 0 0 3px rgba(220,38,38,0.1)
  • Background: White
  • Icon Color: #dc2626

ERROR STATE:
  • Border: 2px solid #dc2626
  • Background: #fef2f2
  • Text Color: #991b1b
  • Error Message: Red text with icon


BUTTON STATES
═════════════════════════════════════════════════════════════════════════════════

DEFAULT STATE:
  • Background: Linear gradient (#dc2626 → #991b1b)
  • Text: White, Bold
  • Padding: 12px vertical, 16px horizontal
  • Cursor: Pointer

HOVER STATE:
  • Shadow: 0 12px 32px rgba(220,38,38,0.4)
  • Transform: translateY(-2px)
  • Cursor: Pointer

ACTIVE STATE:
  • Transform: translateY(0)
  • Shadow: Slightly reduced
  • Feedback: Immediate response


RESPONSIVE BEHAVIOR
═════════════════════════════════════════════════════════════════════════════════

Desktop (≥768px):
  • Two-column grid layout
  • Image visible on left (50%)
  • Form on right (50%)
  • Full height image
  • Padding: 48px/32px

Tablet (640px - 767px):
  • Single column stack
  • Image hidden
  • Form full width
  • Padding: 40px/32px

Mobile (≤639px):
  • Single column stack
  • Image hidden
  • Logo displayed at top
  • Form full width
  • Padding: 32px/16px
  • Touch-optimized spacing


TRANSITIONS & ANIMATIONS
═════════════════════════════════════════════════════════════════════════════════

Input Focus:     0.3s ease (border + shadow)
Button Hover:    0.3s ease (shadow + transform)
Link Hover:      0.3s ease (color change)
All Elements:    Smooth CSS transitions
